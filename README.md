# POKER ROOM

ブラウザーで遊べる、シングルプレイのノーリミット・テキサスホールデムです。ビルドやサーバーは不要で、GitHub Pagesにそのまま公開できます。

## ルール

- 6人卓固定（あなた＋CPU1〜CPU5）
- 各プレイヤーの開始スタックは20BB、ブラインドは0.5/1BB、アンティなし
- 1BB = ¥1,000（開始時の持ち点は¥20,000）
- 52枚を毎ハンドシャッフルし、カードを重複なく配布
- フォールド、チェック、コール、ベット、レイズ、オールイン、サイドポット、引き分けを処理
- 持ち点がなくなると次のハンド開始時に20BBでリバイ

## CPUについて

CPUは6人卓向けの簡易レンジ推定とモンテカルロ持分計算を使います。ポジション、プリフロップの参加・レイズ、直近のアクションを参考に相手のハンド候補をサンプリングし、最大1,000回の試行で勝ち分率を見積もります。ポットオッズ、参加人数、ドロー、ハンドの強さからフォールド／コール／レイズ／ベットを選び、ベット額はプリフロップのオープン／リレイズとポストフロップの小さめ・大きめサイズを使います。

これはCFR等のソルバーでゲーム木を解いた均衡戦略ではなく、GTOそのものではありません。相手のレンジ更新やアクション選択は簡略モデルであり、アクション別EV・混合頻度・均衡性を保証しません。CPUのアクション前には1.4〜2.3秒待ちます。

## 公開

`main` に反映すると GitHub Actions がGitHub Pagesへデプロイします。リポジトリの **Settings → Pages** で公開URLを確認してください。初回はPagesのGitHub Actions公開を有効にする必要がある場合があります。

## 開発

`index.html` 単体で動作します。ブラウザーで開くか、GitHub Pagesでホストしてください。
